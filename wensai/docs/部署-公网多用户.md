# 公网多用户部署（邀请码版）

适用场景：一台云服务器，多个用户从不同网络用浏览器访问，每人只看得到自己的项目。

## 架构

```
浏览器（任意地点）
   │  HTTPS
   ▼
Caddy / Nginx（443，自动证书）
   │  http://127.0.0.1:8765
   ▼
uvicorn（serve.py，同时托管 API 与前端 dist）
   │
   └─ SQLite：data/wensai.sqlite3 ＋ data/projects/<project_id>/
```

## 一、服务器准备

- 2 核 2G 起步（评审任务在进程内跑，人少够用）
- 域名一个（如 `wensai.example.com`），解析到服务器 IP
- 开放 80 / 443

## 二、部署

```bash
# 1. 拉代码
git clone https://github.com/Yuhui-Zhang112/wensai-desktop.git
cd wensai-desktop

# 2. 后端依赖
cd wensai
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3. 前端构建（产物给 serve.py 挂载）
cd ../frontend && npm ci && npm run build && cd ..

# 4. 关键环境变量（必须开 AUTH）
export WENSAI_ENV=production
export WENSAI_AUTH=on
export WENSAI_HOST=127.0.0.1
export WENSAI_PORT=8765
export WENSAI_DB_PATH=/srv/wensai/data/wensai.sqlite3
export WENSAI_FILE_ROOT=/srv/wensai/data/projects
export WENSAI_CORS_ORIGINS=https://wensai.example.com

# 5. 建库 + 生成邀请码
cd wensai
.venv/bin/python -m app.db
.venv/bin/python -m app.invite create --uses 10 --days 30 --note "第一批内测"

# 6. 启动
.venv/bin/python serve.py
```

用 systemd 或 supervisor 守护进程，`serve.py` 会在 8765 监听，只绑本机，由 Caddy 反代。

## 三、Caddy 反代（自动 HTTPS）

```caddyfile
wensai.example.com {
    encode gzip
    reverse_proxy 127.0.0.1:8765
}
```

## 四、必须知道的三个坑

1. **`WENSAI_AUTH=on` 不能忘。** 反代请求都来自 127.0.0.1，如果关掉认证，等于谁都能读别人的材料。
2. **备份。** SQLite 单文件 + 文件目录，每天 `cp` 一次到别处即可：
   ```bash
   tar czf /srv/backup/wensai-$(date +%F).tar.gz -C /srv/wensai data
   ```
3. **上传上限。** 默认 30MB。调大要同时改 `max_file_bytes` 和反代 body 限制。

## 五、邀请码管理

```bash
python -m app.invite create --uses 5 --days 30 --note "给张老师"
python -m app.invite list
```

## 六、当前限制（v0）

- 没有找回密码，忘记只能重建账号
- 没有限流，公网暴露后建议在 Caddy 层加 `rate_limit`
- 任务在进程内执行，同时发起多个长评审会排队变慢
- 没有用量统计和配额

这些在「正式版」里补，不影响小范围试用。
