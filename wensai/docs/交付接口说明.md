# D 与 A/B/C 的实际交付接口 v0.3

这是已交付代码的协议，不是团队原始接口已经同意的标准。D 的主要适配位于 src/services/http.ts，ScopeApproval/VersionActions/FormatReport 有直接调用。后端入口 app/desktop.py，基址 http://127.0.0.1:8765，除明确标明的 A 路由外统一前缀 /api/v1/desktop。JSON 为UTF-8，字段主要用camelCase；A原版本上传字段为snake_case。

完整 HTTP 类型见 openapi.json；启动后也可访问 /docs。项目/材料 ID、versionId、taskId、blockId 必须保留服务返回值，不从名称推导，不传任意磁盘路径。

注意：当前部分适配路由未声明响应response_model，自动生成的OpenAPI对这些JSON响应只给出宽泛schema；不能仅凭它生成完整客户端。请求schema以OpenAPI为准，D响应字段以本文、app/desktop.py的DTO映射及D的domain.ts为准。WebSocket不会包含在HTTP OpenAPI里。

## 路由一览

下表「路径」相对 /api/v1/desktop，所有成功JSON均直接返回对象/数组，无统一 data 包装。未特别说明的成功状态为200；下载为二进制。

| 方法 | 路径 | 请求/响应要点 |
| --- | --- | --- |
| GET | /projects | Project[] |
| POST | /projects | {name} → Project |
| PATCH | /projects/{id} | {name} → {ok:true} |
| DELETE | /projects/{id} | 归档隐藏；保留原件/历史；有活动任务409 |
| GET | /projects/{id}/materials | Material[]，单材料解析失败保留parseError |
| POST | /projects/{id}/materials | multipart file → Material；解析失败仍保留上传 |
| DELETE | /materials/{id} | 归档隐藏；有活动任务409 |
| POST | /materials/{id}/revisions | {sourceVersionId,blocks,rawText?} → Material；仅TXT/MD |
| GET | /versions/{versionId}/download | 指定版本原始二进制；Content-Disposition文件名 |
| GET | /materials/{id}/format?profile=paper | {versionId,report}；proposal/slides亦支持，纯本机B规则 |
| POST | /scope | 见下方确认协议，不入执行队列 |
| POST | /tasks/{id}/confirm | 校验后入队 → Task |
| GET | /materials/{id}/tasks | Task[]，最新先；不列awaiting_confirmation |
| GET | /tasks/{id} | Task |
| POST | /tasks/{id}/cancel | → Task；queued可直接cancelled，running先cancelling |
| PATCH | /tasks/{id}/issues/{issueId} | {decision,editedText?} → Task；只保存处理决定 |
| GET | /tasks/{id}/events?after=0 | {items:[{seq,status,created_at}],next_after}；最多500项 |
| WebSocket | /tasks/{id}/events/ws?after=0 | ws://127.0.0.1:8765/...，按seq推送事件 |
| POST | /materials/{id}/exports | {format:'report'或'text',taskId?,revisionId?} → {name,contentBase64} |
| GET | /service | 模式/provider/模型/大小/凭据说明，无密钥 |

A 原接口：POST /api/v1/materials/{materialId}/versions，multipart 字段 file + source_version_id（必填）。返回 A VersionView，不是 D Material；D 保存成功后重新GET材料列表。此字段用于版本冲突检查，必须传上传前看到的versionId。原接口代码位于app/materials.py。

## 目标与范围确认：必须两阶段

第一步预览：

```json
{
  "materialId":"服务返回的材料ID",
  "profile":"paper",
  "provider":"mock",
  "executionMode":"agent",
  "goal":"重点核对方法、证据和结论是否对应",
  "blockIds":["服务返回的内容块ID"]
}
```

profile 为paper/proposal/slides，映射B的academic-paper-v1/competition-proposal-v1/ppt-defense-v1。provider为mock/deepseek，默认mock。executionMode默认pipeline（兼容旧API），当前D使用agent。agent模式goal不能为空，最长1200字符。blockIds省略为全部可发送文字块，最多512块；空选择或包含未知/图片块会失败。版本由服务取最新，选择文字总量上限375000 UTF-8字节。不发送图片。

响应：taskId、versionId、provider、destination、textDigest、intentDigest、goal、context、executionMode、text、images(空数组)、note。text每项含block_id/kind/source/start/end/text。

D必须展示本轮目标、实际目标服务、完整待发文字、完整context（继续评审的上一轮公开目标/摘要）、多次调用授权说明；用户明确勾选后才提交确认：

```json
{
  "confirmed":true,
  "textDigest":"从预览原样取回的64位摘要",
  "intentDigest":"从预览原样取回的64位摘要"
}
```

intentDigest绑定文字摘要+目标+完整context+provider+模式；不要客户端自行重算或只复用旧勾选。改目标/provider/范围须重预览；版本变化、文件字节不一致或摘要变化返回409。pipeline可不传intentDigest；agent必须传。重复confirm返回409。未confirm任务不运行模型，预览不读凭据。

智能体授权内可能最多8次决策和2轮分块内容评审，工具观察也会参与后续模型决策，不等于单次外发。默认离线不联网；真实模式可能收费，不应自动切换到真实模型。

## 继续评审/追问

在新scope请求增加parentTaskId、填写新的goal。父任务必须属于同材料、execution_mode=agent、状态completed/failed/cancelled。服务只携带上一轮公开目标/回答并标注是否同版本，响应context完整展示给用户，再用新taskId和新intentDigest确认。不会自动恢复后台线程，不覆盖旧轮次；不是无限会话记忆。

## D DTO要点

Project：id/name/updatedAt。

Material：id/projectId/name/kind/createdAt/blocks/revisions/versionId/originalVersionId/rawText/warnings/previewState/demo，失败时parseError。kind为docx/pdf/pptx/txt/md；previewState为ready/awaiting-parser；真实材料demo=false。blocks保留B稳定id，UI kind为heading/paragraph/image，source及page/slide/paragraph/line_start/line_end按解析能力提供，不能伪造DOCX页码。revisions每项含id/name/createdAt/blocks。versionId是当前最新不可变版本，非文件名。

Task：id/materialId/profile/status/progress/progressKnown/eventId/issues/error/createdAt/versionId/provider/result/agent。只有completed可显示100；执行中progressKnown=false，不能伪造模型百分比。result保留完整C ReviewResult（meta/review/issues/total_score），total_score可为null，维度score为0–10，不要强制填0。结果页为最后一次内容评审，各轮完整结果在对应工具观察validated_result中。

UI Issue：id/location/title/severity/category/evidence/standard/original/suggestion/decision/suggestionKind，editedText可选。severity原样保留high/medium/low；location含blockId及可用页/行/段。suggestionKind='advice'，suggestion是修改意见，不是可直接替换正文。

decision为pending/accepted/rejected/edited；edited必须非空editedText，最长20000字符。任务完成后才可处理；保存决定或人工草稿不自动改材料/版本。

agent对象：mode('agent'或'pipeline')/goal/parentTaskId/answer/termination/steps。steps每项seq/action/status/label/observation/createdAt。action是plan或白名单工具，status为running/completed/failed/cancelled。工具记录是公开操作和观察，不是隐藏思维链。

termination=finished/needs_input/step_limit。needs_input、step_limit的任务也可status=completed，只表示本轮停止，不表示目标已成功。answer为综合文字，未做逐句原文证据校验，可核验引文以C报告为准。

## 状态、事件与恢复

awaiting_confirmation → queued → running → completed/failed；取消经cancelling → cancelled，排队取消可直接cancelled。awaiting_confirmation不会入队。服务重启将未结束任务标为failed或cancelled，不自动重发外部请求。

eventId等于desktop_events最新seq。订阅时after传最后处理的seq，服务先发送已有事件后持续查询；每条HTTP/WS事件含seq/status/created_at。收到大于cursor的seq后GET任务当前快照并更新，忽略重复/旧seq。事件是通知，不保证一次快照只包含该事件时刻的中间状态。

WS断线用HTTP补拉，达到500条时继续按next_after取；前端重连以最后cursor恢复。未知任务可能4404，来源拒绝1008，不能无限重试权限错误。不要把WS事件与SSE的id格式混用。

## 保存、导出与错误

TXT/MD修订传rawText避免空行重排，sourceVersionId必填，旧版本409。浏览器可能规范化CRLF，原件下载始终保留二进制。Office/PDF不支持把建议自动替换正文，Office修改后走同格式新版本上传；PDF界面只读。

report导出包含Task和完整C/agent公开记录；text仅导出已保存的最新TXT/MD，不自动应用accepted意见。响应contentBase64要解码为字节，按name保存，保留原件。UI先选择保存路径，后请求和写文件。

错误统一为 {"error":{"code":"VERSION_CONFLICT","message":"中文提示","details":[]}}，details可省略。前端优先显示error.message。常见状态：403 Host/Origin限制、404不存在/归档、409版本/确认/状态冲突、413过大、415格式不支持、422输入或解析错误、503数据库忙。

上传上限30MiB；普通JSON沿用A约1MiB请求体限制（UTF-8编码计量），不是所有30MiB文本都能在编辑器一次保存。后端只绑定回环并校验Host/Origin，不是远程鉴权服务，不要开放公网或通配CORS。
