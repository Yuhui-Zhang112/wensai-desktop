# 已实现的 ABCD 本地接口

## 智能体新增协议（v0.3）

原 /scope 新增 executionMode='agent'、goal（1–1200字）、可选 parentTaskId。返回 intentDigest、goal、context、executionMode，原 textDigest/文字选段不变。confirm 除 confirmed=true、textDigest 外，agent 模式必须提交 intentDigest，绑定文字+目标+完整上一轮公开摘要+provider+模式；错误返回409。executionMode 默认 pipeline 以兼容旧调用，D界面已切换为agent。

Task DTO 新增 agent：mode/goal/parentTaskId/answer/termination/steps。steps 含 seq/action/status/label/observation/createdAt，是公开操作与真实工具观察，不是隐藏思维链。termination 可为 finished、needs_input、step_limit；后两者不是目标已成功。用户补充通过新scope+parentTaskId创建新轮，不能绕过再次确认。JSON导出包含全部公开工具记录，各C轮validated_result亦保留。

运行层 app/agent_runtime.py 复用已列的任务/取消/WebSocket路由，无任意工具执行HTTP端点。工具白名单与边界见智能体设计.md。旧C分块引擎保留为review_content工具，不直接冒充自主决策循环。

基址 http://127.0.0.1:8765，桌面前缀 /api/v1/desktop，不是旧 D 临时契约。A 原始 /api/v1 端点仍保留；A 管理 SQLite/版本文件，B/C 使用独立 Python 模块。

| 方法 | 桌面路由 | 用途 |
| --- | --- | --- |
| GET/POST | /projects | 列出/创建项目 |
| PATCH/DELETE | /projects/{id} | 重命名/归档隐藏 |
| GET/POST | /projects/{id}/materials | 列材料/上传并 B 解析 |
| DELETE | /materials/{id} | 归档隐藏，保留文件历史 |
| POST | /materials/{id}/revisions | TXT/MD 新版本，rawText、sourceVersionId |
| GET | /versions/{id}/download | 指定版本二进制 |
| GET | /materials/{id}/format?profile=paper | B 格式报告，另支持 proposal/slides |
| POST | /scope | 固化范围、版本、摘要；不调用模型 |
| POST | /tasks/{id}/confirm | confirmed=true 与 textDigest 验证后执行 |
| GET | /materials/{id}/tasks | 持久化任务历史 |
| GET | /tasks/{id} | 状态、完整 C 结果与处理决定 |
| POST | /tasks/{id}/cancel | 请求取消 |
| PATCH | /tasks/{id}/issues/{issueId} | 决定/人工草稿，不修改材料 |
| GET | /tasks/{id}/events?after={seq} | HTTP 补拉 |
| WebSocket | /tasks/{id}/events/ws?after={seq} | 持久化 seq 续传 |
| POST | /materials/{id}/exports | report 完整 JSON；text 仅已保存 TXT/MD |
| GET | /service | 整合服务说明 |

Office 新版本使用 A 原路由 POST /api/v1/materials/{id}/versions，multipart 字段 file。下载/版本创建复用 A，验证 managed bytes SHA256。错误为 error.message。

任务：scope → awaiting_confirmation → confirm → queued → running → completed/failed；取消经 cancelling → cancelled。前端不伪造模型百分比。服务重启将未结束执行标记失败，不自动重发外部请求。

desktop_tasks.result_json 保存完整 C schema，允许空 total_score，维度分值不擅自换算；不能套旧 A 必填数字总分。建议是 advice，不是段落替换正文。用户决定单独保存。desktop_events 为递增持久化 seq；desktop_audits 保存 C 脱敏尝试记录，不含原始模型输入输出和密钥。

scope 参数含 materialId、profile、provider(mock/deepseek)、可选 blockIds；返回真实文字/source、versionId、textDigest、目标。confirm 校验不可变文件、最新版本和摘要，变化返回 409。未确认不执行；默认 Mock，真实服务须用户主动选择并逐次确认，仅发送文字。

安全继承 A：回环监听、Host/Origin 校验、managed path 校验、原件不覆盖。归档不物理删除。不是远程多用户认证接口。
